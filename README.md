# Vray VPN

اپلیکیشن VPN هوشمند اندروید مبتنی بر هسته‌ی Xray-core — اتصال با یک لمس، انتخاب خودکار سریع‌ترین سرور، حالت هوشمند، منطقه‌ای و دستی، و تونل تفکیکی (Split Tunneling).
